## 1. 総合診断

**現状のサイトは「上質だが匿名的」。個人ブランドとしての際立ちを弱めている要因は、装飾の不足ではなく“作者の不在”である。**

現行デザインの水準は率直に言って高い。Navy×Cream×Sageの配色、Cormorant Garamond×Inter Tightの組み合わせ、余白の取り方は、フリーランス翻訳者のサイトとしては上位数%に入る。土台を壊す必要はない。

その上で、「個人としての顔が際立たない」根本原因は次の5点に集約される:

### 診断① サイト全体に「顔」が1枚もない（最重要）
- サイト唯一の人物写真（`static/images/portrait.jpg`）は**後ろ姿で海を見ている構図**。ホームの第7セクション（最下部近く）に初登場し、顔は最後まで見えない。
- **Aboutページには写真が1枚もない**。海外IP弁護士が「この人は誰か」を確認しに行く最重要ページが、テキストのみ。
- さらにこの後ろ姿写真が**og:image**（`head.html:15,24`）に設定されているため、メール・LinkedIn・Slackでリンクが共有された瞬間のプレビューも「匿名の浜辺の人」になる。
- ターゲット読者は「日本にいる一個人に送金して大丈夫か」を判断する。顔の不在は美学ではなく、**発注前の最後の摩擦**として機能してしまっている。

### 診断② レイアウト文法が「企業の発表」であって「個人の声」ではない
- ヒーロー中央揃え、セクションラベル中央揃え、ステップ中央揃え、CTA中央揃え——**ほぼ全要素がセンター配置**。センター配置は式典・企業型の文法で、対称性が匿名性を生む。
- コピーは強い一人称（"I handle the judgment."）なのに、視覚がそれを「誰かの言葉」として提示していない。thesis banner の名言も**無署名**。
- 唯一の非対称セクション（About preview: 左テキスト右写真）が、ページ内で最も「人がいる」感触を出している。これが証拠。

### 診断③ ページが9枚の「帯」の連打で、プレミアムテンプレの既視感が出る
ホームは navy→beige→cream→white/navy→beige→navy→cream→beige→cream→navy と**10回近く背景色が切り替わる**。この「色帯×中央ラベル×カードグリッド」のリズムは高級系Squarespace/Webflowテンプレの標準文法で、洗練はしているが**誰のサイトでもありうる**。際立ちを削っているのは品質不足ではなくこの既視感。

### 診断④ 数字が主役なのに、数字の組版が主役扱いされていない
- ヒーローh1の「13 million+」がCormorant Garamondのオールドスタイル数字で描画され、実表示で**「r3 million+」に見えかける**（1512px実測スクリーンショットで確認）。信頼の核となる数字の可読性が落ちている。
- 最強の実績証拠「~12,000語の医療機器特許を13日前倒し納品」が、stats barの下の**イタリック注記1行**に格下げされている。しかも「May 24」に年がなく、2027年に読むと鮮度不明＝経年劣化する書き方。

### 診断⑤ 「レビュアーの眼」というポジショニングが、コピーにしか存在しない
差別化の核（translation notes・用語ガード・26,000行の自作システム）は全てテキストの主張止まり。**成果物そのものを見せていない**。testimonial 0件・リピート0件を正直開示する戦略を取っている以上、代わりの証拠は「仕事の現物」しかない。ここが最大の未開拓地。

**結論: 方向性は「もっと飾る」ではなく「作者を可視化し、現物で証明する」。** 以下の提案はすべてこの一軸に沿う。

## 2. 優先順位付き改善提案リスト

優先順位の判断軸: **「ターゲット読者（発注判断者）の信頼形成に効く順」**。着手コストが低く効果が高いものを上位に繰り上げてある。P1のみユーザーの写真撮影が必要（Sonnetでは完結しない）。

### P1. 顔の見えるポートレート導入【インパクト最大・要ユーザー撮影】

**何を**: 顔が判別できるポートレート写真を1枚（できれば2枚）用意し、3箇所に配置する。

**どこを**:
1. **Aboutページ冒頭** — `content/about/index.md` のh1直下に右寄せ配置。`main.css` に追加:
   ```css
   .about-portrait { float: right; width: 240px; margin: 0 0 1.5rem 2.5rem; }
   .about-portrait img { border-radius: 2px; }
   .about-portrait figcaption { font-size: 0.82rem; color: var(--color-body-soft); margin-top: 0.6rem; line-height: 1.5; }
   @media (max-width: 640px) { .about-portrait { float: none; width: 200px; margin: 0 auto 2rem; } }
   ```
   figcaption例: `Soma Furuie — Kyoto, Japan` ＋ LinkedIn/ProZリンク（診断⑤のD-3と連動）。
2. **ホームのAbout preview**（`home.html:151-153`）— 現在の海写真を新ポートレートに差し替え。現在の`aspect-ratio: 7/5`のままでよい。
3. **og:image / twitter:image**（`head.html:15,24`）— P9のOGカード（顔＋名前＋役割）に差し替え。

**海の写真の処遇**: 廃棄しない。Aboutページ後半「Why Patents」節の情緒的な挿絵として残す（後ろ姿は「本文中の1枚」なら効く。「唯一の顔」だから問題なだけ）。

**なぜ個人ブランドを強めるか**: 発注者の与信確認は「実在する・信頼できそうな個人か」の確認であり、顔はその最短経路。センター配置の匿名的テンプレ感（診断②）も、実在の顔が入るだけで大きく崩れる。**サイト全体で最も費用対効果が高い1手**。

**撮影ガイド（ユーザー向け）**: 自然光・無地または書斎/作業環境の背景・視線はカメラまたは手元の書類・服装は現行写真のニット程度のスマートカジュアルで十分。**腕組み+ぼかしオフィスの「コンサル風」は撮らない**（トーン逸脱）。縦3:4と横7:5の2構図あると使い回しが利く。

### P2. ヒーローの個人化＋数字の可読性修正【30分で終わる高視認箇所】

**何を/どこを**:
1. **名前を最初の画面に入れる** — `home.html:6` のh1の直前に eyebrow 行を追加:
   ```html
   <p class="hero-eyebrow">Soma Furuie — EN→JA Patent Translator, Kyoto</p>
   ```
   ```css
   .hero-eyebrow { font-family: var(--font-sans); font-size: 0.8rem; font-weight: 600; letter-spacing: 0.18em; text-transform: uppercase; color: rgba(255,255,255,0.55); margin-bottom: 1.6rem; }
   ```
   現状、彼の名前はロゴ（左上1.55rem）にしか存在せず、ヒーローは無記名の宣言になっている。
2. **オールドスタイル数字の修正** — h1内の数字をサンセリフ化:
   ```html
   sharpened by <span class="num">13 million+</span> words
   ```
   ```css
   .hero h1 .num { font-family: var(--font-sans); font-weight: 600; font-size: 0.88em; letter-spacing: -0.02em; }
   ```
   実測で「13」が「r3」に読める描画になっており（Cormorantのオールドスタイル数字）、**核となる主張数字がワンビートで読めない**。`font-variant-numeric: lining-nums` はCormorant Garamondがlining字形を持たないため効かない可能性が高く、span方式が確実。
3. **固定`<br>`の削除** — `home.html:6,8` のh1とhero-sub内の`<br>`を削除し、`max-width`で改行を制御（h1側に `max-width: 17ch; margin-inline: auto;` 等）。375px幅では固定改行が不自然な5行折返しを生む（モバイル改善G-1を兼ねる）。

**なぜ**: ファーストビュー3秒で「誰が・何を・どれだけの裏付けで」が揃う。数字修正は信頼の核の可読性回復。

### P3. 「証拠の現物化」— translation notes 抜粋セクション新設【差別化の本丸・実装のみで完結】

**何を**: 実際の納品物「translation-notes document」の一般化した抜粋（2〜3項目）を、書類のartifactとして見せるセクションをホームに新設する。

**どこを**: `home.html` の How It Works セクション直後（Mid CTAの位置。P6でMid CTAは削除するのでそこに入れ替え）。構成案:

```html
<section class="section">
  <div class="container">
    <div class="section-header">
      <p class="section-label">What You Receive</p>
      <h2>Every delivery includes my translation notes.</h2>
    </div>
    <div class="notes-artifact">
      <p class="notes-artifact-title">Translation Notes — excerpt (details generalized)</p>
      <dl>
        <dt>Note 3 — Reference sign</dt>
        <dd>Element "42a" in claim 5 appears as "42b" in Fig. 3. Cross-checked against all drawings; rendered as 42a and flagged for your review.</dd>
        <dt>Note 7 — Source ambiguity</dt>
        <dd>"the member" in ¶[0034] has two possible antecedents. Context of ¶[0029] indicates the sealing member; translated accordingly, with the alternative reading noted.</dd>
        <dt>Note 12 — Source typo</dt>
        <dd>"though hole" in ¶[0041] read as "through hole" based on Fig. 6; translated as 貫通孔.</dd>
      </dl>
    </div>
  </div>
</section>
```

スタイルは「書類らしさ」に振る: 白背景・`border: 1px solid var(--color-border)`・上辺のみ`3px solid var(--color-accent)`・dtはInter 600 0.82rem uppercase・ddは通常本文・最大幅720px中央。ホバー効果なし（カードではなく文書なので動かない方が正しい）。

**注意（制約遵守）**: 実案件の固有情報は使わない。上記例文のように**実際のノートで頻出するパターンの一般形**をSomaさん自身が監修して2〜3件書く（存在しない実績の捏造ではない。「こういう指摘が載った文書が毎回付く」という事実の提示である）。文言は実装時にSomaさんの確認を挟むこと。

**なぜ**: testimonial 0件戦略の代替証拠は「仕事の現物」しかない。弁護士は成果物のサンプルで職能を判断する職業であり、reference signの取り違いや先行詞の曖昧性を具体的に指摘する文書の抜粋は、**どんな形容詞よりも雄弁**。同業の翻訳者サイトで納品物の中身を見せている例はほぼなく、差別化としても最強クラス。

## 3. やらないほうがいいこと

1. **AI生成の顔写真・イラスト肖像で「顔問題」を解決しない**。実在性の証明が目的なのに合成顔を使うのは自殺行為。本人撮影が用意できるまではP1を保留し、他を先行させること。
2. **偽の社会的証明の追加禁止**（既存制約の再確認）: testimonial捏造・「Trusted by」ロゴ壁・会員バッジ風装飾。P3のnotes抜粋も、実在パターンの一般形であることをSomaさん監修で担保する。
3. **フォント・配色の全面リブランドはしない**。Cormorant Garamondは確かにプレミアムテンプレ頻出フォントだが、置き換えの手間に対して得られる差別化はP1/P3/P7より遥かに小さい。現行の骨格は上質であり、際立ちは「作者の可視化」で作る。
4. **CTAを増やさない・煽らない**。カウントダウン、"Only 2 slots left"、ポップアップ、チャットウィジェットは全てトーン破壊。本提案はむしろCTAを5→3に削っている（P6）。
5. **動きを足さない**。パララックス、スクロール連動アニメ、タイプライター効果等。現行のヒーローfadeUp 1回が上限。静けさが差別化資産。
6. **グラデーション・ガラスモーフィズム・ストックフォト**（過去に明示却下済み・再確認のみ）。
7. **「Reviewer」を見出し語に昇格させない**。P3/P7でレビュアー性を強調するが、あくまで「翻訳の裏付け」の文脈で。セクションタイトルに"Review Services"のような語が出たら骨格違反。

## 4. 参考にすべき原理（実例つき・抽象化）

### 原理1: 「サイト自体を文書品質のサンプルにする」— Matthew Butterick / Practical Typography
弁護士向けに書かれた組版論の古典。効いているのは「法律家は文書で生きる職業であり、目の前の文書の組版精度を書き手の職能の代理指標として無意識に読む」という洞察。装飾ゼロ・完璧な行長・階層・数字組版だけで信頼を構築している。**適用**: P8（行長720px・lining数字・階層逆転解消）はこの原理の直接実装。「特許翻訳者のサイトの組版が甘い」は減点が二重になる職業であることを意識する。

### 原理2: 「会社の発表」ではなく「一人の書き手の文書」のレイアウト文法 — 独立プラクティショナーのエディトリアルサイト（例: Frank Chimero、個人スタジオの作家系サイト）
効いているのは、①左揃えの見出し、②本文中の一人称と顔写真の近接、③署名的デバイス（手書き署名・自筆風下線・落款）が**1つだけ**あること。センター対称＝組織、左非対称＋署名＝個人、という文法を一貫させている。**適用**: P6（左揃え化・帯削減）とP7(署名・下線)。重要なのは署名デバイスを「1つだけ」に絞る自制で、これが上品さと記憶性を両立させる。

### 原理3: 「主張ではなく工程の現物を見せる」— 日本の工房・職人ブランドの証拠設計（例: 刀鍛冶・木工工房のサイトが作業台と道具を見せる構造）
効いているのは、「私は丁寧です」と言う代わりに**砥石と鉋屑を写す**こと。閲覧者は工程の精度から品質を推論する。推薦文が構造的に存在しない一人親方の職業で発達した、社会的証明の代替様式。**適用**: P3（translation notes現物）とP4（納品台帳）。彼の「作業台」は26,000行のPythonと用語ガードとノート文書であり、これらをartifactとして提示することが、testimonial 0件戦略の下で取りうる最強の証拠設計。

## 実装順サマリ（Sonnet 5向け）

| 順 | 提案 | 規模 | ユーザー準備 |
|---|---|---|---|
| 1 | P5 Blogをnavから外す | 5分 | 不要 |
| 2 | P2 ヒーロー個人化＋数字修正 | 30分 | 不要 |
| 3 | P4 納品台帳 | 30分 | 不要 |
| 4 | P3 notes抜粋セクション | 1-2h | 文言最終確認のみ |
| 5 | P6 帯削減・左揃え化 | 2-3h | 不要 |
| 6 | P8 タイポ階層 | 1h | 不要 |
| 7 | P7 署名モチーフ | 1h | 不要 |
| 8 | P10 モバイル仕上げ | 1h | 不要 |
| 9 | P1 ポートレート配置 | 1h | **要: 写真撮影** |
| 10 | P9 OGカード・favicon | 1h | P1の写真 |

P1の写真が用意できるまで、P5→P2→P4→P3→P6の順で進めれば、写真なしでも診断①以外の全課題が解消する。
